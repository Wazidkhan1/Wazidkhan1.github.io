# Wazid Khan — Portfolio

Personal portfolio for Wazid Khan, an undergraduate student at IIT Goa.

**Website:** https://wazidkhan1.github.io/

## Featured projects

- [Sentinel](https://github.com/Wazidkhan1/fraud-detection-system): transaction risk monitoring with Node.js, Express, TensorFlow.js, and PostgreSQL.
- [FraudWebsiteDetect](https://github.com/Wazidkhan1/FraudWebsiteDetect): website fraud signal analysis with Python, Flask, Gemini, and MongoDB.
- [SearchSphere](https://github.com/Wazidkhan1/Search-engine): crawling, indexing, and ranked search with React, Node.js, and PostgreSQL.

## Development

This is a static website with no build step or runtime dependency. Open `index.html` in a browser or serve this directory with a static HTTP server. Google Fonts are optional; local fallback fonts are provided.

- `index.html`: content, project links, and accessible navigation.
- `styles.css`: responsive layout and project concept illustrations.
- `script.js`: progressive project filtering and footer year. All projects remain visible when JavaScript is disabled.
- `markdown/Readme.md`: earlier academic notes, preserved from the original site.

Project visuals are illustrative concepts, not screenshots or live results. Repository links lead to the source code; this site does not host the project applications.

GitHub Pages publishes the root of the `main` branch. Edit project details in `index.html` and push changes to update the portfolio.
